Testupplägg

  1. Öppna appen på datorn och välj Dator / livevy.
  2. Skanna QR-koden med telefonen. Telefonen ansluter till samma molnsession.
  3. Starta kameran och ta överlappande bildrutor längs pinnen.
  4. Vrid pinnen 60–100° och välj Ny rotation.
  5. Datorn visar materialet och markerar bildrutor som riskerar att vara oskarpa.
